# Status-noter for FUO-vagtplan

Denne fil er oprettet af GitHub Copilot som et sted, hvor du kan skrive korte noter eller opdateringer (f.eks. ændringer du laver i README), så jeg kan hente dem senere og bruge dem til at generere en status eller opdatere filer i repoet efter aftale.

Dato for oprettelse: 2026-09-02
Oprettet af: @copilot (automatiseret log)

Hvordan bruge filen
- Skriv dine korte noter/ændringer som punktopstillinger nedenfor.
- For hver note, start linjen med en dato i format YYYY-MM-DD og en kort titel, fx:
  - 2026-09-02 — README: opdateret sektion "Ændringer" med nye punkter
- Når du er klar, skriv `@copilot: opdater status` som en linje for at bede mig om at læse filen og opdatere README eller lave et commit/PR.

Eksempel:
- 2026-09-02 — README: tilføjet note om rotationsliste for vagter
